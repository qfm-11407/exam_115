# 實際 AI 評分與整題週期測試｜工具 v1.3.1

這個測試會真正使用 GAS 已設定的 API 金鑰與模型，產生 API 費用。金鑰不會下載到本機或寫入報告。測試批次評分加速需先依 [UPDATE_2.12.0.md](UPDATE_2.12.0.md) 更新 GitHub 網頁、GAS Code.gs 與 Student HTML，再更新原部署。既有金鑰與網址保留。

## 執行

1. 將修正包解壓到目前的 `oneword` 測試資料夾，覆蓋同名檔案，保留 `.local` 資料夾。
2. 雙擊 **TEST_GAS_AI_28.cmd**。
3. 在新開啟的瀏覽器登入教師端，再回命令視窗按 Enter。若有未結束的測驗，先到教師端結束後再執行。
4. 確認顯示「測試工具版本：1.3.1」、「GAS 後端版本：2.12.0」及「AI 正式判讀」。工具會建立獨立的 AI 壓測房間。

舊的 `TEST_GAS_30.cmd` 預設仍是「只測上傳」的流程演練，不會呼叫 AI。

## 會實際完成哪些步驟

- 28 個隔離的學生頁加入，另開教師與大螢幕，共 30 個頁面。
- 經實際滑鼠操作寫入筆跡，以共同預定時間按送出；實際時間差記在 `clickSpreadMs`。
- 檢查所有圖片保存、學生端確認及原圖雜湊一致。
- 保持教師頁與學生頁開啟，等待 **28 份 AI 判讀全部完成**。不會在上傳完成時停止。
- 等教師端公布按鈕可用，實際按公布，等待 GAS 確認；檢查每位學生顯示對應的答對／答錯結果。
- 檢查大螢幕兩頁共 28 人的原圖及判定。24 格排列時會實際切換到第二頁。
- 自確認公布起保留至少 8 秒，再按開始下一題，確認 28 個學生頁都能作答、大螢幕也已換題。
- 只替第一題送圖及呼叫 AI；第二題用於確認換題及解除鎖定，不再送圖。完成後結束本工具建立的測驗；`--keep-room` 可保留供檢查。

效能測試固定手寫「木」，成語答案依正式規則隨機抽選。因此所有人都答錯也可能正常；本測試驗證實際 AI 與完整流程的效能，不以答對率驗證辨識準確率，也不使用預設假判定。

## 通過條件

確認批次評分時，摘要應有 `judgingEngine: "gas-batch"`；`single-answer` 表示仍使用舊後端。摘要應是 `scope: "ai-full-cycle"`、`mode: "live"`、`realAI: true`。

必須同時滿足：28 張保存及核對成功、28 個學生端確認、28 份狀態為 done 且結果為 true／false、至少 28 次 AI 成功回應、全部學生結果顯示成功、大螢幕結果驗證成功，以及下一題全員可以作答。

只完成上傳、AI 尚在排隊、AI 服務失敗或仍有「無法判定」，均不會宣告完整測試通過。工具不會對服務失敗自動按「重新判讀」；辨識不明時仍沿用正式後端既有的最多兩次判讀規則。`successfulAiCalls` 是後端記錄的成功回應數，不是所有 HTTP 請求數，也不是精確帳單。

## 時間欄位

摘要 `timingSeconds` 全部以秒為單位：

| 欄位 | 意義 |
|---|---|
| sendToUploadConfirmed | 同步送出至所有學生頁確認圖片已保存 |
| sendToAllAiJudged | 同步送出至觀察到全部 AI 判讀完成，包含上傳及排隊 |
| remainingAiWaitAfterUploads | 全部確認保存後，還要等待 AI 的時間；已提前完成則為 0 |
| averageAiTimePerAnswer | GAS 記錄的平均 AI 等待耗時，不含排隊；批次模式記錄該份所在批次的 HTTP 等待時間，不是各請求的精確獨立耗時；兩次判讀包含兩次等待 |
| sendToRevealed | 同步送出至確認公布 |
| roundStartToRevealed | 題目開始至確認公布，使用 GAS 同一時鐘計算 |
| roundStartToNextQuestionReady | 題目開始至確認下一題全員可以作答，包含公布停留及換題 |

`serverTiming.queueMs` 保留平均排隊時間；`aiSettings` 記錄本次的模型與同時判讀份數。工具沿用現有設定，不會更改模型或併發數。

狀態約每 3 秒觀察一次，公布及學生端還有各自輪詢延遲，因此週期數值是實際測試的觀察時間，非精確事件時間。檢查兩頁大螢幕若超過 8 秒，工具會保留超出的檢查開銷於 `resultDisplayExtensionMs`；不會將這段隱藏成純 AI 耗時。單台電腦開 30 頁仍不能完全代表校內 28 台平板與 Wi-Fi。

## 其他參數

預設作答上限 180 秒、上傳觀察 180 秒，另外給 AI 最多 600 秒；全員提早保存會依正式規則提早收卷。

```bat
TEST_GAS_AI_28.cmd --students 5
TEST_GAS_AI_28.cmd --seconds 30 --send-at 29
TEST_GAS_AI_28.cmd --judge-timeout 1200
TEST_GAS_AI_28.cmd --channel msedge
```

第一次可先測 5 人，確認 API 額度、模型與結果顯示；28 人的速度仍須實際跑 28 人，不能以 5 人數據推估。
