## 最快測試

1. 解壓 `oneword-github-test.zip`，上傳內容到測試儲存庫，啟用 GitHub Pages。
2. 依部署說明建立 GAS，貼上 gas/ 下的三個檔案，執行 setup_、設定 ALLOWED_ORIGINS 並部署。
3. `config.js` 已預設本教室 GAS 網址，開啟網站即可直接進入教師端或學生端。更新網頁檔案會保留此預設，不需每次重新貼上網址；只有更換後端部署時才需修改。
4. 教師以登入碼進入，建立「流程演練」，學生加入後設定題數與結果停留秒數，按「開始整場自動測驗」，測試存圖、公布、換題與總成績。
5. 設定自己的 API 金鑰，另建「AI 正式判讀」房間，開始真正筆跡測試。

演練明確標示為模擬，不辨識實際筆跡，不呼叫 AI。真正判讀需自備金鑰與額度，仍可能誤判細微缺筆或潦草字形。

## 資料與測試

多人送圖與自動重試測試見 [LOAD_TEST.md](LOAD_TEST.md)。`TEST_GAS_30.cmd` 可在本機開啟 28 個學生頁＋教師＋大螢幕，實際測試 GAS／Drive；需先更新部署，並在測試瀏覽器登入。尚未實測通過，不代表已能穩定承載 30 個真實裝置。

圖片保存在教師私人 Drive，API 金鑰保存在 GAS Script Properties；兩者不放在 GitHub。教師頁需保持開啟以處理等待中的判讀。GAS 配額與瀏覽器背景節流會影響即時性，正式使用前需校內實測。

在上層既有專案執行 `npm run test:oneword` 測試，`npm run package:oneword` 產生乾淨上傳包，不需新套件。GAS 與頁面測試使用服務／DOM／訊息替身，不消耗真實 API；不等同於已部署至 Google 或實測平板。

`public/`、server.mjs、ai.mjs、START.cmd 與 tests/ 是上一版本機程式供參考，**不是 GitHub Pages 入口**。scripts/prepare-web.mjs 可從保留介面來源產生雲端頁面，修改時需同步調整產生器。

`github-upload/` 與 ZIP 已排除 `.local/` 本機比賽資料、舊伺服器與測試檔。請勿把本機 `.local/` 上傳公開儲存庫。

## 學生登入白名單

只允許 `1410701–1410715`（15 人）及 `1420716–1420728`（13 人），共 28 個學號。其餘學號一律由 GAS 後端拒絕，不能靠修改網頁繞過；舊版其他學號的裝置權杖也不能恢復登入或交卷。教師仍使用原教師登入碼。更新此限制後，請同時更新 GitHub 網頁與 GAS 的正式部署版本。

## 成語隨機填空

題庫沿用專案內 `Idioms/idioms1150101.html` 的既有成語目錄，共 148 則四字成語，來源範圍見 `Idioms/SOURCE_SCOPE.md`。每次先隨機選一則成語，再獨立隨機選第 1、2、3 或 4 字挖空，共 592 種成語／位置組合。同一場已正式出題的成語不再重複；重抽未開始的預覽不占題數。

例如「金蘭之交」可出成「□蘭之交」、「金□之交」、「金蘭□交」、「金蘭之□」，正解分別是「金、蘭、之、交」。學生仍只手寫一個字。

建立房間會產生私人預覽；教師可按「隨機抽題」重抽，再確認秒數按「開始作答」。揭曉後自動準備下一題預覽。成語與挖空位置由後端保存，開始時依預覽識別碼取得正解，不採用網頁自行傳送的題目或答案。舊預覽識別碼會被拒絕。學生在揭曉前只能取得挖空題目；揭曉後顯示正解與完整成語。

此更新須同步上傳新版網頁，並把 `gas/Code.gs` 更新至 GAS 正式部署的新版本（2.2.0）。已存在而沒有預覽的舊房間，可在題目結束後按「隨機抽題」產生新預覽。

## 確認目前判讀模式

教師台會固定顯示後端金鑰設定狀態及目前房間模式。套用 AI 設定只會儲存金鑰、模型與同時判讀數；不會改變已建立的演練房間。後端已設定金鑰時，可按「建立 AI 正式比賽」開啟建立房間視窗，確認後取得新房號。若目前題目未揭曉，須先完成本題。學生須使用新房號加入。僅套用模型而未設定金鑰時，畫面會明確提示金鑰尚未設定。


## 測驗管理

- 「結束測驗」會停止加入、交卷與新的背景判讀。已揭曉成績保留，尚未揭曉的當題取消、不計分；不必等待卡住的判讀工作。
- 「管理舊測驗」可重新整理清單、載入或刪除測驗。刪除會移除房號索引並使舊房號失效，Drive 圖片與 JSON 備份保留；不會移到垃圾桶或永久刪除。刪除後不占系統保留 30 場測驗的索引名額。
- 已結束的測驗載入後仍維持結束狀態。
- 「AI 設定」套用成功且後端已有金鑰時，會自動開啟建立 AI 挑戰的視窗。已有未結束測驗時，須勾選確認先結束；按下建立後取得新房號，學生再加入。設定為同一 GAS 後端的多台教師端會共用目前測驗。
- 已發出的 API 請求無法保證中止或免計費；結束測驗會阻止後續啟動與重試，晚到的結果不會計分。用量仍以服務商帳單為準。
- 網頁測試使用 GAS、DOM 及訊息替身驗證，並非真實 Google 部署或平板測試。此版本的測驗管理功能以 GAS 網頁版為準，保留的本機舊版不提供管理功能。

## v2.3.0 移除學生並重新加入

教師台每位參賽者旁新增「移除」按鈕，確認後撤銷舊裝置登入並暫時移出清單。同一個允許學號可立即重新加入同房間，即使本題作答中亦可恢復既有參賽者。累計成績、順序、已保存的手寫圖片與已交卷答案保留；已交卷的答案仍然鎖定，不會因重新加入而獲得重寫機會。若移除時有尚未保存成功的上傳，舊請求不能回寫新連線；重新加入後仍須在截止前送出。

舊裝置收到名單更新後會回到加入頁，清除失效登入權杖。同學號僅允許一個有效登入，教師的過期移除請求不能撤銷已重新加入的新連線。已結束測驗不提供移除重連。移除不會封鎖該學號，也不會刪除成績。GAS 2.3.0 後端必須一併更新。

學生頁改為只顯示「限本班學號加入」，後端仍維持原 28 個學號白名單。加入時會顯示連線進度並避免連續點擊重複送出。iPhone 連線速度尚未進行實機比較；此進度提示不代表伺服器已加速。


## v2.4.0 手機直連作答與加入恢復

針對「教師端已加入、手機仍等待回覆」的情況，新增由 GAS HTML Service 直接提供的 Student 頁面。教師台讀到後端支援後，分享及測試作答預設改用同部署的 `/exec?view=student&room=房號`，學生操作不再經 GitHub 頁面內的隱藏 GAS 橋接框架。教師台與大螢幕仍留在 GitHub。

每次新裝置加入前會建立隨機的私人恢復識別並保存；後端只保存其摘要。同房號、同學號、同一識別重試會恢復同一參賽者，不新增重複紀錄，也不因本題已開始而卡住。同學號的其他裝置無法使用不同識別取回既有登入。教師移除裝置也會撤銷原識別；學生明確重新加入會產生新識別。識別不放在分享網址或公開名單。

舊版已卡住且沒有恢復識別的學生，請教師先按「移除」，再用新複製的直連網址加入。Student.html 由 scripts/prepare-student.mjs 依既有學生頁與畫布程式產生，不需另維護畫布或判分流程。GAS 需新增名為 Student 的 HTML 檔並更新正式部署，否則不能使用新網址。

這是針對通訊流程的相容性修正，已以 Google 服務及 DOM 替身測試；尚未在實際 iPhone 上驗證，不保證可解決所有網路、Google 服務或 iOS 版本差異。GAS 配額與 AI 費用不變。


## v2.5.0 提前截止與揭曉效果

- 背景判讀仍從交卷後開始；全員交卷後可直接展示筆跡。尚有排隊或判讀中的答案不能揭曉；對錯仍由教師按「揭曉對錯」統一公開。

- 新題恢復原畫面；未交卷、無法判定等狀態不套用對錯顏色。系統減少動態效果設定會停用動畫。
- 大螢幕手寫字在色底上以白色顯示，原始 PNG 不變，點圖放大仍可查看原圖。
- 使用者已回報 iPhone 相容作答可連線；本次新特效尚未以 iPhone 實機驗證。需要一併更新 GAS Code.gs 與 Student.html 並更新原部署。

## v2.6.0 預設平板模式

首頁學生入口與教師分享網址預設使用 GAS 直接作答頁（原相容模式）。平板、手機直向採上下排列，寬度至少 700px 的橫向螢幕採題目／按鈕與手寫區並排。書寫區依可用寬高調整，保留捲動以供小螢幕使用，控制按鈕至少 44px。旋轉只改顯示尺寸，不清除筆跡；送出仍是 512 × 512 PNG。

## v2.7.0 交卷傳送緩衝

每題的作答時間結束後加上 5 秒接收緩衝。例如設定 30 秒，第 30 秒鎖定手寫區，至第 35 秒前接收延遲交卷；期間筆跡與判定保持隱藏，不能揭曉。全員圖片已存好時可提前截止，教師手動截止則立即停止新交卷。已按送出的圖片在裝置上鎖定並暫存，重試只送同一張圖，不開放修改；後端已受理的存圖可在緩衝結束後完成。

這是短暫延遲的緩衝，完全斷線或超過緩衝才首次抵達的請求仍可能無法交卷。僅新開始的題目套用；舊進行中題目維持原截止時間。詳見 UPDATE_2.7.0.md。

## v2.8.0 判讀、圖片與同步優化

- 教師端每份判讀完成後立即接續待處理答案，不必等下一次定時查詢。當佇列為空或出錯時停止接續，等下次狀態同步再試，避免空轉；仍受原本後端 1～3 份同時判讀上限保護。工作綁定房號與題目，避免舊工作接到新題。
- 大螢幕依學生識別碼補抓新增圖片，已載入圖片留在瀏覽器；後端每張圖分別快取，超出單張快取門檻仍可從 Drive 讀取。只在截止後提供圖片，保密與緩衝規則不變。
- 房間摘要沒變時省略重複 Script Properties 寫入；當時房間主狀態立即存 Drive；v2.11.0 起改用活動狀態持久化儲存及階段備份，詳見本版更新說明。每次判讀只讀一次模型與同時份數設定。
- 教師端在待判讀、緩衝、倒數末段約隔 1.5 秒再查狀態；一般約 3.5 秒。大螢幕在等待出題、末段倒數、緩衝及截止後約隔 1.2～1.5 秒再查；平板模式倒數最後 8 秒與緩衝期約隔 2.5～3.3 秒，一般約 3.5～4.3 秒。以上是查詢完成後的間隔，另有實際網路／GAS 耗時；不增加同一頁重疊的狀態查詢。
- 教師台 API 使用量下方新增「本題速度紀錄」，顯示受理等候、圖片保存、排隊、AI 與受理至判讀完成的平均耗時。僅教師快照可見，不包含平板到 GAS 的網路耗時；舊紀錄無計時欄位則顯示尚無紀錄。

此版本保留 5 秒傳送緩衝、已送出筆跡鎖定與同圖重送。未做校內多裝置實際速度比較，不能據程式測試推定實際加速倍數。

## v2.9.0 整場自動測驗

建立新房間、學生加入後，設定 1～148 題、每題作答秒數，以及結果停留時間（預設 8 秒，可設 5～30 秒），按一次「開始整場自動測驗」。學生交卷即背景判讀，全員交卷或時間到截止，完成判讀後自動公布結果，再進入下一題；最後一題顯示完成與總成績。保留 5 秒傳送緩衝。

成語在同一房間內不重複，僅空格位置繼續隨機。手動模式也遵守不重複規則，舊場次會由成績備份補齊已用成語。教師可暫停自動公布／換題、繼續或結束；暫停不凍結當題作答計時，已送出答案仍會判讀。服務／存圖失敗會暫停，供教師重試或明確略過不計分；兩次仍辨識不明會顯示無法判定、不計分並繼續。

請保持至少一個已登入的教師頁開啟。整場由教師頁輪詢驅動後端，頁面關閉、登出或遭瀏覽器暫停會延後判讀與換題；重新進入可恢復同一場，已開始題目的時限不凍結。自動設定須在新房間第一題前完成；已開始的手動場次請另建房間。詳見 UPDATE_2.9.0.md。

## v2.9.2 全班大螢幕排列

橫向螢幕可用區域至少 900 × 600 CSS 像素時，答案牆會依目前人數與畫面高度排列。25 人為 5 × 5，26～28 人為 6 欄 × 5 列；少人時自動減少行列。題目區縮短，答案卡與最終排行榜共用可用高度，保留學號、姓名、分數與對錯。字跡維持原比例，點圖仍可放大。建議按右上角全螢幕；較窄或直向畫面沿用可捲動排列。已用 GAS 2.9.0 者僅需更新網頁。

## v2.9.3 固定 6 × 4 大螢幕

16:9 大螢幕固定 24 格，不足保留空位；超過 24 人可翻頁查看，其餘人的登入、交卷、計分資格不變。排行榜每頁 24 人並延續名次。已使用 GAS 2.9.0 者只更新 GitHub 網頁。

## v2.10.0 教師設定每排格數

教師台「大螢幕排列設定」可選每排 3～8 格，預設 6 格。每頁最多 24 人，列數自動計算；例如 4 格 × 6 列、6 格 × 4 列、8 格 × 3 列，最後一列可能未填滿。超過 24 人可切換頁面，參賽資格不變。套用會保存到本房間，所有大螢幕及教師端同步，不影響題目、倒數或成績。需 GAS 2.10.0 或更新版。
