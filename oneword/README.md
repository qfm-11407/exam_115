## 最快測試

1. 解壓 `oneword-github-test.zip`，上傳內容到測試儲存庫，啟用 GitHub Pages。
2. 依部署說明建立 GAS，貼上 gas/ 下的三個檔案，執行 setup_、設定 ALLOWED_ORIGINS 並部署。
3. `config.js` 已預設本教室 GAS 網址，開啟網站即可直接進入教師端或學生端。更新網頁檔案會保留此預設，不需每次重新貼上網址；只有更換後端部署時才需修改。
4. 教師以登入碼進入，建立「流程演練」，分享學生網址，測試 Drive 圖片、答案牆、揭曉及計分。
5. 設定自己的 API 金鑰，另建「AI 正式判讀」房間，開始真正筆跡測試。

演練明確標示為模擬，不辨識實際筆跡，不呼叫 AI。真正判讀需自備金鑰與額度，仍可能誤判細微缺筆或潦草字形。

## 資料與測試

圖片保存在教師私人 Drive，API 金鑰保存在 GAS Script Properties；兩者不放在 GitHub。教師頁需保持開啟以處理等待中的判讀。GAS 配額與瀏覽器背景節流會影響即時性，正式使用前需校內實測。

在上層既有專案執行 `npm run test:oneword` 測試，`npm run package:oneword` 產生乾淨上傳包，不需新套件。GAS 與頁面測試使用服務／DOM／訊息替身，不消耗真實 API；不等同於已部署至 Google 或實測平板。

`public/`、server.mjs、ai.mjs、START.cmd 與 tests/ 是上一版本機程式供參考，**不是 GitHub Pages 入口**。scripts/prepare-web.mjs 可從保留介面來源產生雲端頁面，修改時需同步調整產生器。

`github-upload/` 與 ZIP 已排除 `.local/` 本機比賽資料、舊伺服器與測試檔。請勿把本機 `.local/` 上傳公開儲存庫。

## 學生登入白名單

只允許 `1410701–1410715`（15 人）及 `1420716–1420728`（13 人），共 28 個學號。其餘學號一律由 GAS 後端拒絕，不能靠修改網頁繞過；舊版其他學號的裝置權杖也不能恢復登入或交卷。教師仍使用原教師登入碼。更新此限制後，請同時更新 GitHub 網頁與 GAS 的正式部署版本。

## 成語隨機填空

題庫沿用專案內 `Idioms/idioms1150101.html` 的既有成語目錄，共 148 則四字成語，來源範圍見 `Idioms/SOURCE_SCOPE.md`。每次先隨機選一則成語，再獨立隨機選第 1、2、3 或 4 字挖空，共 592 種成語／位置組合。抽樣允許重複。

例如「金蘭之交」可出成「□蘭之交」、「金□之交」、「金蘭□交」、「金蘭之□」，正解分別是「金、蘭、之、交」。學生仍只手寫一個字。

建立房間會產生私人預覽；教師可按「隨機抽題」重抽，再確認秒數按「開始作答」。揭曉後自動準備下一題預覽。成語與挖空位置由後端保存，開始時依預覽識別碼取得正解，不採用網頁自行傳送的題目或答案。舊預覽識別碼會被拒絕。學生在揭曉前只能取得挖空題目；揭曉後顯示正解與完整成語。

此更新須同步上傳新版網頁，並把 `gas/Code.gs` 更新至 GAS 正式部署的新版本（2.2.0）。已存在而沒有預覽的舊房間，可在題目結束後按「隨機抽題」產生新預覽。


## 校務入口連線修正

連線時自動將校務網域入口轉為同部署的一般 `/macros/s/…/exec` 入口，避免校務網址導向 Google 登入。設定與本機儲存識別維持原值，既有房間、登入及作答權杖可繼續使用。GAS 部署仍須允許未登入者存取。此修正只需更新網頁檔案，無須修改 GAS 程式。


## 確認目前判讀模式

教師台會固定顯示後端金鑰設定狀態及目前房間模式。套用 AI 設定只會儲存金鑰、模型與同時判讀數；不會改變已建立的演練房間。後端已設定金鑰時，可按「建立 AI 正式比賽」開啟建立房間視窗，確認後取得新房號。若目前題目未揭曉，須先完成本題。學生須使用新房號加入。僅套用模型而未設定金鑰時，畫面會明確提示金鑰尚未設定。


## 測驗管理

- 「結束測驗」會停止加入、交卷與新的背景判讀。已揭曉成績保留，尚未揭曉的當題取消、不計分；不必等待卡住的判讀工作。
- 「管理舊測驗」可重新整理清單、載入或刪除測驗。刪除會移除房號索引並使舊房號失效，Drive 圖片與 JSON 備份保留；不會移到垃圾桶或永久刪除。刪除後不占系統保留 30 場測驗的索引名額。
- 已結束的測驗載入後仍維持結束狀態。
- 「AI 設定」套用成功且後端已有金鑰時，會自動開啟建立 AI 挑戰的視窗。已有未結束測驗時，須勾選確認先結束；按下建立後取得新房號，學生再加入。設定為同一 GAS 後端的多台教師端會共用目前測驗。
- 已發出的 API 請求無法保證中止或免計費；結束測驗會阻止後續啟動與重試，晚到的結果不會計分。用量仍以服務商帳單為準。
- 網頁測試使用 GAS、DOM 及訊息替身驗證，並非真實 Google 部署或平板測試。此版本的測驗管理功能以 GAS 網頁版為準，保留的本機舊版不提供管理功能。
