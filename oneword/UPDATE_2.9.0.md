# OneWord 2.9.0 整場自動測驗

教師設定題數後，整場依序自動判讀、公布、換題與結算；同一場成語不重複。

## 更新步驟

1. 解壓縮 oneword-v2.9.0.zip，內容覆蓋 GitHub 原本 oneword/，提交更新。
2. GAS 原專案的 Code.gs 覆蓋為 gas/Code.gs；Student HTML 覆蓋為 gas/Student.html。Bridge 不變。
3. 在原部署選「部署 → 管理部署作業 → 編輯 → 新版本 → 部署」。不需重跑 setup_，原網址、金鑰與資料保留。
4. 各端重新整理／重新開啟作答頁。教師台確認「網頁 v2.9.0 · GAS 2.9.0」，學生頁確認「平板模式 v2.9.0」。

## 使用方式

1. 建立新比賽，選 AI 正式判讀（或流程演練），分享學生網址。
2. 等待應參賽的學生全數加入。
3. 在「整場自動測驗」設定本次題數（1～148）、每題作答時間（10～180 秒）與結果停留時間（5～30 秒，預設 8 秒）。其他允許字形僅適用第一題。
4. 按一次「開始整場自動測驗」。其後不用逐題按開始或揭曉。

學生交卷即背景判讀；全員圖片存好則提前截止，否則依作答時間與 5 秒緩衝截止。所有待判讀完成後，系統自動公布並計分，停留設定秒數後下一題；最後一題停留結束後結算，大螢幕自動顯示總排行榜，仍可切回最後一題答案牆。未交卷者不計分。

## 控制與例外

- 「暫停自動流程」停止自動公布／下一題，當題計時與已送出答案的判讀繼續。按「繼續自動流程」可恢復；若停在結果畫面，重新給完整停留時間。
- AI 服務錯誤或圖片保存失敗會暫停。可按重新判讀，或請學生重送已鎖定圖片；恢復後自動接續。也可按「略過未判定並繼續」，未判定答案不計分。
- 兩次仍辨識不明的答案以「無法判定」公布，不強制判錯，仍可進入下一題。
- 結束／刪除仍可立即停止整場，尚未公布的當題不計分，已公布成績保留。
- 題數與自動模式須於新房間第一題前設定。取消勾選自動模式可沿用手動操作；同場成語也不重複。
- 正式出題才占用成語；預覽重抽不占用。舊場次會從既有成績備份補齊已使用成語。學生在公布前不能取得正解、下一題預覽或已用成語清單。

## 運作條件與驗證

至少保持一個已登入的教師控制台開啟。教師頁輪詢驅動後端判讀、公布與換題；教師頁關閉、登出或遭瀏覽器暫停時可能延後，重新進入恢復同一場，已開始題目的作答時限仍持續。

測試涵蓋完整多題流程、148 個成語不重複、題數上限、緩衝、重複請求與多教師快照防止雙重計分／跳題、暫停恢復、失敗重試、保密、學生倒數換題及最終排行榜。未在真實教室多台裝置進行完整連續測驗。
