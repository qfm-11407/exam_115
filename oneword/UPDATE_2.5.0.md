# OneWord 2.5.0 更新

新增全員交卷提前截止，以及紅綠底揭曉特效。延用已確認可連線的手機相容作答頁。

## 更新步驟

1. 解壓縮 oneword-v2.5.0.zip，將網頁檔案覆蓋至 GitHub 原本的 oneword/，提交更新。
2. GAS 原專案覆蓋 gas/Code.gs 全文。
3. GAS 的 Student HTML 覆蓋為 gas/Student.html 全文。若還沒有 Student，新增 HTML 檔名填 Student。Bridge.html 與 appsscript.json 未更改。
4. 「部署 → 管理部署作業 → 原部署 → 編輯 → 新版本 → 部署」。不需重跑 setup_，金鑰、登入碼與既有資料保留。
5. GitHub 頁面部署完成後按 Ctrl+F5，確認教師台「網頁 v2.5.0 · GAS 2.5.0」。重新複製作答網址，手機頁應顯示「手機作答 v2.5.0」。

## 全員交卷後

- 例如設定 30 秒，全員在第 12 秒已完成存圖，系統即自動截止，不必再等 18 秒。
- 判斷以伺服器保存圖片完成為準，尚在上傳者仍須等待；失敗的上傳不會被誤算為完成。
- 截止後大螢幕顯示筆跡，背景繼續判讀。所有待判讀完成後，教師仍需按「揭曉對錯」。
- 若移除尚未交卷者，會以剩下的參賽者計算全員；目前名單為零時不觸發。

## 揭曉效果

- 答錯：整張紅色答案卡、大型叉號、短暫震動。
- 答對：整張綠色答案卡、大型勾號、短暫放大與星光。
- 學生頁也會變成對應色底，新題時恢復原色。
- 未交卷、無法判定維持中性色，不會被誤標為答錯。
- 同一判定的動畫每題只播放一次，排行榜切換與名單更新不會重播。
- 原始手寫 PNG 不變，大螢幕顏色變換只影響展示；點圖放大仍可看原圖。

程式測試未替代實際投影機與 iPhone 的視覺驗證。
