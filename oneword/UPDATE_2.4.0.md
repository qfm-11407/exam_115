# OneWord 2.4.0 更新：手機直連作答

針對 iPhone 上「教師已看到加入成功，手機一直等待至逾時」的情況，新增直接由 GAS 提供的學生作答頁，並補上回覆遺失後的安全恢復機制。尚未進行實機 iPhone 驗證。

## 更新步驟（需同時完成）

1. 解壓縮 oneword-v2.4.0.zip，將網頁檔案覆蓋到 GitHub 原本的 oneword/，提交更新並等待 Pages 部署完成。
2. 打開原 GAS 專案，將 gas/Code.gs 全文貼上覆蓋並儲存。
3. 在 GAS 左側檔案旁按「＋ → HTML」，名稱填 Student，貼上包內 gas/Student.html 全文。若已建立，覆蓋即可。
4. Bridge.html 與 appsscript.json 本次未改動；不需重新初始化，不需重填既有金鑰、教師登入碼與 Drive 設定。
5. 「部署 → 管理部署作業 → 選原部署 → 編輯（鉛筆）→ 新版本 → 部署」。沿用原部署網址與原本允許學生匿名存取的權限。
6. 教師頁按 Ctrl+F5，確認顯示「網頁 v2.4.0 · GAS 2.4.0」。

## 讓卡住的 iPhone 重新加入

1. 教師先在參賽者名單移除該學號的舊連線。這只處理舊版已加入但沒有取回登入權杖的紀錄，成績與已交卷答案保留。
2. 教師按「一鍵複製作答網址」，重新分享。更新成功後，網址會是 script.google.com/macros/s/原部署ID/exec?view=student&room=原房號。
3. iPhone 使用新網址，畫面會顯示「手機作答 v2.4.0」，輸入同學號加入。不要繼續使用舊的 GitHub student.html 書籤。
4. 確認手機進入作答畫面，再測試手寫與交卷。

## 運作差異

- 教師台、大螢幕仍在 GitHub；學生頁改由 GAS 提供，直接呼叫同專案的後端。
- 網址只包含部署識別、頁面種類與房號，不包含學生登入權杖或恢復識別。
- 新版加入前會保存隨機恢復識別；回覆偶發遺失時，同一裝置重試可恢復原加入紀錄。未接收到回覆的請求不代表未執行，因此不可盲目新增學生。
- 已送出答案仍鎖定；同一學號不允許其他裝置接管。教師移除後才可明確重新加入。
- 程式測試不等於已在 iPhone 或 25 台實機驗證；仍需校內測試。
