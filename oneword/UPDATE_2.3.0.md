# OneWord 2.3.0 更新步驟

本次新增教師移除學生連線、允許同學號重新加入，須同時更新網頁與 GAS。

1. 解壓縮 oneword-v2.3.0.zip，將網頁檔案覆蓋到 GitHub 原本的 oneword/，提交並等待 Pages 部署完成。不要直接上傳 ZIP，不要再多包一層資料夾。
2. 使用原 GAS 專案，將包內 gas/Code.gs 全文貼上覆蓋並儲存。Bridge.html 與 appsscript.json 本次未更改。
3. 到「部署 → 管理部署作業 → 選原部署 → 編輯（鉛筆）→ 新版本 → 部署」。沿用原部署可保持網址。
4. 不需重新執行 setup_；既有 API 金鑰、教師登入碼、房間與 Drive 資料夾設定保留。
5. 教師與學生頁重新整理；教師台應顯示「網頁 v2.3.0 · GAS 2.3.0」。若 GAS 仍是舊版，請確認更新的是原網址對應的部署。

## 移除與重新加入

- 在教師台的參賽者名單，按該學號旁的「移除」，閱讀並確認。
- 舊裝置的登入會失效；同學號可以重新輸入學號加入相同房號，已開始的當題也可重新連線。
- 原有累計成績與已交卷答案保留。已交卷者不能重新作答本題。
- 尚未交卷者重新連線後，仍須在截止前送出。
- 舊裝置收到更新後會返回加入頁；網路不通時無法立即顯示，但伺服器已拒絕舊權杖的新操作。
- 已結束的測驗維持關閉，不能透過移除學生恢復作答。

## 其他調整

- 學生登入頁提示簡化為「限本班學號加入」，實際白名單限制維持原 28 個學號。
- 加入房間時顯示「正在連線」，並暫停重複點擊。
- 未進行 iPhone 與其他裝置的實機速度對照；連線提示不是效能保證。
