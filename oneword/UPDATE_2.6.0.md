# OneWord 2.6.0 更新

原「相容模式」改稱「平板模式」，首頁學生入口與教師複製網址預設使用 GAS 直接作答。手機也使用同一入口。

## 更新步驟

1. 解壓縮 oneword-v2.6.0.zip，將內容覆蓋 GitHub 原本 oneword/ 內的檔案，提交更新。
2. GAS 原專案的 Code.gs 覆蓋為 gas/Code.gs；Student HTML 覆蓋為 gas/Student.html。Bridge 不變。
3. 在原部署選「部署 → 管理部署作業 → 編輯 → 新版本 → 部署」。不需重跑 setup_，後端網址、金鑰、登入碼與資料保留。
4. 重新整理首頁／教師頁並重新複製學生網址。學生頁應顯示「平板模式 v2.6.0」。

## 版面

- 直向：題目、方形手寫區、工具與送出按鈕上下排列。
- 橫向且寬度至少 700px：左側題目與送出，右側手寫區。
- 手寫區依寬高調整，最高 560 CSS 像素；短螢幕縮小書寫區，仍可捲動。
- 按鈕至少 44px；登入欄位至少 16px 字體；支援安全區與瀏覽器縮放。
- 螢幕旋轉只改顯示大小，已寫筆跡保留，送出仍為 512 × 512 PNG。

程式測試與版面規則檢查不等於實機驗證，請在實際平板直向、橫向各寫一字並送出確認。
