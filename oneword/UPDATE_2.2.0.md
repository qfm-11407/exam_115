# OneWord 2.2.0 更新步驟

這次新增「結束測驗」「管理舊測驗／刪除」，並改善 AI 挑戰的建立流程。網頁和 GAS 要一起更新。

1. 解壓縮 oneword-v2.2.0.zip，將網頁檔案覆蓋至 GitHub 原本的 oneword/，提交更新。不要直接上傳 ZIP，也不要多包一層資料夾。
2. 使用原 GAS 專案，將包內 gas/Code.gs 全文貼上覆蓋。Bridge.html 與 appsscript.json 本次未更改；若原本缺少檔案，可使用包內版本補齊。
3. 儲存後，到「部署 → 管理部署作業 → 選取目前部署 → 編輯（鉛筆）→ 新版本 → 部署」。沿用原部署即可保持網址。
4. 不需重新執行 setup_，不需重填已保存的 OPENAI_API_KEY、TEACHER_PIN、DRIVE_FOLDER_ID。API 金鑰不可放進 GitHub。
5. 網頁部署完成後按 Ctrl+F5 重整，重新登入教師台。若顯示後端需要更新至 2.2.0，代表正式部署尚未切到新版本。

## 開啟 AI 評分挑戰

- 金鑰狀態應顯示「AI 金鑰：後端已設定」。這表示已找到設定，是否可成功呼叫 API 仍以實際交卷判讀為準。
- 點「建立 AI 正式比賽」，或在「AI 設定」套用後直接進入建立視窗。
- 若有舊測驗，勾選「我確認結束目前測驗，再建立新房間」。未揭曉的當題取消、不計分；已揭曉成績保留。
- 確認判讀方式為「AI 正式判讀」，按「建立房間」，學生使用新房號加入。

## 結束與刪除

- 只按「截止・展示筆跡」是結束本題作答，整場測驗仍存在。
- 按「結束測驗」可以直接結束整場，無須等所有判讀完成；確認後停止新交卷與新判讀。
- 「刪除此測驗」可移除目前測驗；「管理舊測驗」可選擇舊場次刪除。每次刪除都會要求確認。
- 刪除是從系統清單移除並使舊房號失效。Drive 中的原始圖片、成績與 JSON 備份保留，不會移到垃圾桶或永久刪除。
- 已送出的 API 請求仍可能產生費用；結束後晚到的結果不會計分。

保留的本機 Node 版本供參考，本次管理功能適用於 GAS 網頁版。
